 Баг-репорты (день 7)

 BUG-07-01: Попытка создать дубликат файла

**Серьёзность:** средняя
**Приоритет:** средний
**Статус:** закрыт (не воспроизводится)

**Шаги воспроизведения:**
1. Создать файл /dup.txt с содержимым "a".
2. Повторно создать файл /dup.txt с содержимым "b".

**Ожидаемый результат:** второй вызов возвращает -1.
**Фактический результат:** второй вызов возвращает -1.
**Причина:** в fs.create_file есть проверка на существование.
**Решение:** дефект не обнаружен, поведение корректное.
