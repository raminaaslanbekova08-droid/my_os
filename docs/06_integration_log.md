 Журнал интеграции (день 6)

 Сквозной сценарий

  1. Вход администратора
Команды: login → admin → secret. Результат: Вы вошли как admin. OK.

  2. Создание файлов
create → /report.txt → quarterly report (id=1)
create → /notes.txt → my notes (id=2). OK.

 3. Список и чтение
ls → /report.txt, /notes.txt
cat /report.txt → quarterly report. OK.

 
  4. Запуск процессов
run editor → PID=1
run browser → PID=2. OK.

 5. Завершение и память
kill 1 → Процесс 1 завершён
mem → 10 / 1024 МБ. OK.

 6. Журнал
logs 5 → последние 5 записей. OK.

 Обработка ошибок

1. Неверный пароль — Ошибка входа, система не падает.
2. Несуществующий файл — (файл пуст или не существует).
3. Несуществующий процесс — Не удалось завершить.
4. Удаление чужого файла — Нет прав на удаление.
