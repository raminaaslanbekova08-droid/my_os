 Системные сценарии

 SS-01: Первый запуск ОС

**Предусловие:** файл db/os.sqlite отсутствует.

**Шаги:**
1. Удалить db/os.sqlite.
2. Запустить python -m src.db.
3. Убедиться, что файл создан.
4. Открыть через SQLite Viewer.
5. Проверить таблицы: users, processes, files, syscalls_log,
   memory_state, roles.
6. Проверить, что roles содержит admin, user, guest.

**Ожидаемый результат:** база создана, таблицы присутствуют.

 SS-02: Работа администратора

**Шаги:**
1. Запустить python -m src.shell.
2. Войти как admin.
3. Создать /ss02_a.txt.
4. Создать /ss02_b.txt.
5. Прочитать /ss02_a.txt.
6. Запустить процесс app1.
7. Запустить процесс app2.
8. Вывести список процессов.
9. Завершить процесс app1.
10. Проверить память.
11. Выйти.

**Ожидаемый результат:** все команды выполнены.

 SS-03: Работа обычного пользователя

**Шаги:**
1. Запустить оболочку.
2. Войти как user.
3. Создать свой файл /ss03_my.txt.
4. Попробовать удалить /ss02_a.txt от admin.
5. Запустить процесс user_app.
6. Попробовать завершить процесс admin.
7. Выйти.

**Ожидаемый результат:** свои действия разрешены, чужие запрещены.

 SS-04: Обработка ошибок

**Шаги:**
1. Запустить оболочку.
2. Попробовать войти с неверным паролем.
3. Войти с правильным паролем.
4. Прочитать несуществующий файл.
5. Завершить несуществующий процесс.
6. Создать дубликат файла.
7. Убедиться, что система продолжает работать.
8. Выйти.

**Ожидаемый результат:** все ошибки обработаны, ядро не падает.
