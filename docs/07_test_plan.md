 Тест-план StudyOS

 1. Введение

Тестируется учебная операционная система StudyOS, реализованная
на Python 3.10+ с использованием SQLite. Цель тестирования —
убедиться, что все модули работают согласно спецификациям и
нефункциональным требованиям.

 2. Объём тестирования

Входит:

- модульное тестирование каждой функции db.py, kernel.py, auth.py;
- функциональное тестирование системных вызовов syscalls.py;
- интеграционное тестирование связок между модулями;
- системное тестирование сквозных сценариев;
- регрессионное тестирование после исправлений.

Не входит:

- тестирование производительности под высокой нагрузкой;
- тестирование на реальном аппаратном обеспечении;
- тестирование сетевых сценариев;
- тестирование графического интерфейса.

 3. Виды тестирования

- Модульное — для каждой отдельной функции.
- Функциональное — для системных вызовов.
- Интеграционное — для связок shell → syscalls → fs.
- Системное — для сквозных сценариев.
- Регрессионное — после каждого исправления.

 4. Ресурсы

Инструменты: VS Code, Python 3.10+, SQLite, SQLite Viewer, Git.
Документация: матрица трассируемости из 03_Module_Specifications.md.

 5. Расписание

- День 7 — стратегия, тест-план, тест-кейсы, модульные тесты.
- День 8 — функциональные и интеграционные тесты.
- День 9 — системное и регрессионное тестирование.

 6. Критерии

Начало: все модули реализованы, интеграционные тесты проходят.

Окончание:

- все модульные тесты проходят;
- все функциональные тесты проходят;
- все интеграционные тесты проходят;
- все системные сценарии выполнены;
- дефекты зафиксированы в баг-репортах;
- требования верифицированы по матрице трассируемости.
