 Обработка ошибок (день 4)

 1. sys_login с несуществующим пользователем

**Шаги:** `sys_login('nobody', 'wrong', 'guest')`.

**Ожидаемый результат:** False.

**Фактический результат:** False.

**Причина:** пользователь не найден в таблице users.

 2. Регистрация с существующим логином

**Шаги:** `register_user('admin', 'newpass', 'admin')`.

**Ожидаемый результат:** None.

**Фактический результат:** None.

**Причина:** проверка через `execute_select` находит существующего пользователя.

 3. Пустой пароль

**Шаги:** `register_user('empty', '', 'user')`.

**Ожидаемый результат:** None (в нашей реализации — отклоняется, т.к. len < 4).

**Фактический результат:** None.

**Замечание:** в реальной ОС следовало бы добавить более строгую валидацию.

 4. Превышение лимита памяти

**Шаги:** `kernel_instance.allocate_memory(5000)`.

**Ожидаемый результат:** False.

**Фактический результат:** False.

**Причина:** 5000 > 1024 (лимит).

 5. sys_kill для несуществующего PID

**Шаги:** `sys_kill(99999, 'admin')`.

**Ожидаемый результат:** False (но с точки зрения прав — не DENIED).

**Фактический результат:** True (на дне 4 это заглушка).

**Замечание:** на дне 5 будет реальная проверка через scheduler.
