 Интеграционные сценарии

 IS-01: Создание файла
Участники: user, shell, syscalls, fs, db.
Предусловие: admin авторизован.
Результат: файл создан, запись в syscalls_log со статусом OK.

 IS-02: Чтение файла
Результат: содержимое выведено.

 IS-03: Удаление чужого файла
Участники: user, shell, syscalls, auth, fs, db.
Результат: отказ, статус DENIED в журнале.

 IS-04: Запуск процесса
Участники: user, shell, syscalls, kernel, scheduler, db.
Результат: процесс создан, память выделена.

 IS-05: Завершение процесса
Результат: процесс завершён, память освобождена.

 IS-06: Сквозной сценарий администратора
login → create → cat → run → ps → kill → mem → exit.

 IS-07: Сквозной сценарий обычного пользователя
login → create свой файл → попытка удалить чужой → run → kill чужой → exit.
